# SportDrive

Автоматизована інформаційна система для обліку оренди спортивного інвентарю. Розроблена як курсовий проєкт із дисципліни «Проєктування автоматизованих інформаційних систем».

Програма призначена для ведення каталогу спорядження, обробки замовлень, обліку клієнтів та організації роботи працівників пункту прокату.

## Можливості

- Розмежування доступу між менеджером, працівниками та кіоском самообслуговування.
- Перегляд, пошук і редагування каталогу спорядження.
- Оформлення оренди, видачі та повернення інвентарю.
- Облік клієнтів та історії замовлень.
- Створення й розподіл завдань між працівниками.
- Внутрішній чат і журнал дій користувачів.
- Облік фінансових операцій у демонстраційному режимі.

## Встановлення

Завантажити останню версію можна в розділі **Releases**.

**Інсталятор:**
1. Завантажити `SportRentApp_setup.exe`.
2. Запустити інсталятор і виконати встановлення.
3. Відкрити SportDrive через створений ярлик.

**Портативна версія:**
1. Завантажити `SportRentApp-portable.zip`.
2. Розпакувати архів у будь-яку папку з правами запису.
3. Запустити `SportRentApp.exe`.

## Системні вимоги

- Windows x64
- .NET Framework 4.7.2 або сумісна новіша версія

## Використані технології

- C# / WPF
- .NET Framework 4.7.2
- Entity Framework 6
- SQLite

## Примітки

Програма використовує локальну базу даних SQLite. Для роботи не потрібне підключення до інтернету.

Фінансові операції реалізовані в демонстраційному режимі без інтеграції з платіжними системами.
