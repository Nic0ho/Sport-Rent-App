# Sport Drive

Локальна система прокату спортивного спорядження: WPF, .NET Framework 4.7.2, Entity Framework 6 та SQLite. Розрахунки демонстраційні: програма веде журнал, а не переказує гроші.

## Запуск готового комплекту

Потрібні Windows x64 і .NET Framework 4.7.2 або сумісна новіша версія .NET Framework.
